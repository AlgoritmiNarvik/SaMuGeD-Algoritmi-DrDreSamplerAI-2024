## 2026-10-07: offline identity enrichment from MusicBrainz dumps

Added four sidecar layers that resolve work identity evidence without the one request per second API limit. `musicbrainz_dump` verifies the CC0 JSON dumps against the signed checksum list and stream filters works and artists into a local subset bound to the queue titles and creator names, with whole dump namesake counts. `work_identity_offline` applies the existing title and writer agreement rules against that subset for every source, records title only namesakes for review and estimates composition terms from composer life spans. `provenance_hints` extracts collection codes, date claims, attribution markers and upstream declarations from existing labels and assigns a claim class and search route to every source. `candidate_assessment` tiers unreviewed candidates from the API and dump indexes with duplicate and provider cross checks and writes a bounded review packet.

The classifier for creator labels now treats unknown author markers in several languages and traditional spellings as unattributed. None of the new layers writes to the working API index, promotes a candidate to a verified identity or treats a declaration or life span as rights clearance. The Lakh recording lookup continues through the pinned API runtime under a local chain supervisor with archived receipts.

Validation: 821 tests passed in the full suite. On the local corpus the dump subset holds 164,091 works and 97,747 artists; the offline pass covers all 208,212 sources in 15 seconds with 6,217 work candidates, 326,224 title only rows and 2,706 creator identity candidates. Corpus data, dump archives and receipts remain local.
