How rankings were created and what the numbers mean

Source: audited aligned_closed build, phrases. The corpus keeps up to three selected candidates of each type per MIDI. Rankings use the saved results and search has limits.

Within a song, occurrences do not overlap and include the source phrase once. Sorting uses occurrence count, duration in quarter-note beats, note count and recurrence score. Ties use file path and ID. Each position has one normalized artist/title pair. Across arrangements, only the maximum result is used and counts are not added.

Motif filter: at least 8 notes, 4 distinct pitches and 4 quarter-note beats. General MIDI bass programs 32 through 39 and parts labelled bass, basse, bajo, drum, drums, percussion or beat box are excluded. This is a structural filter and its settings can change the ranking.

Popular songs is a curated listening collection. Selection methods and sources are documented in the repository.

Shared families use the saved signature of pitch intervals from the first note and quantized rhythm. This is a structural match and does not prove common origin or equal recognizability.

Audio uses the same FluidSynth and FluidR3 GM rendering as the main player. WAV is 48 kHz stereo PCM 24 bit and loops until stopped. The rendered source cycle can extend beyond the detector excerpt. A labelled piano preview changes only the timbre. These are MIDI instrument renders, not original recordings. Source coordinates, file hashes and counts were checked for every shown phrase. Listener ratings are not used or required for this analysis. Rendered audio loops are available in the SaMuGeD Earworms Space.
